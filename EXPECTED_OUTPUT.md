# Expected Output

This document summarizes the expected output of a successful run of the LAVrefiner heritability reproduction pipeline using the packaged variants from VNTR regions on chromosomes 1–10 and expression phenotypes on chromosome 1. Compare these reference values with the outputs generated by the commands in [README.md](README.md).

## 1. Environment and packaged tools

The reference results below use the following tool versions. Bundled executable details are recorded in [tool_manifest.json](tool_manifest.json).

```text
LAVrefiner 0.3.1
MAFFT v7.526
PLINK v1.9.0-b.7.7 64-bit
GCTA v1.94.4 Linux
```

The prepared dataset should contain:

```text
VCF samples       : 731
chr1 phenotypes   : 1974
Phenotype samples : 731
```

## 7. Expected final mean h²

`Mean_hsq` is the mean of the available per-phenotype heritability estimates for each model. `N_valid` counts phenotypes with a non-missing estimate, and `N_total` counts all phenotypes evaluated for that model. Fits without an estimate do not contribute to the mean.

```text
Model                     Mean_hsq             N_valid   N_total
LAV                       0.15327779310344827  1856      1974
rLAV_nLAV                 0.1563022999461497   1857      1974
VNTR_CN                   0.15660394325481797  1868      1974
CN_rLAV_nLAV_pruned       0.1645905422077922   1848      1974
```
